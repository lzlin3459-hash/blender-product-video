# 从产品效果图重建标签

## 判断输入属于哪一类

- 平面展开稿：优先作为纹理，确认尺寸、接缝方向及环绕顺序。
- 真正绕产品拍摄的照片：可能具有不同透视、遮挡和光照，需对照三维结构做投影校准。
- 同一桶体模板上的标签平移效果图：桶体、提手和高光几乎不动，只有标签变换位置。这类图未必遵循真实圆柱投影，不能固定按每张90度拼接。

判断依据来自重复图案和结构位置，不以文件名“正/侧/背”作为相机角度证明。圆柱、锥桶、方盒需要不同UV与几何模型。

## 最小可行路线

1. 先做一张正面投影样板，把几何可编辑性与标签可读性分开验证。原始图片可整张加载，通过UV只采样标签区域；无需重写文字或修改原图。
2. 对多图的重叠内容做分析：标题边界、插画、徽章、二维码区域等。需要时用特征匹配（如SIFT加匹配过滤）估算位移，但必须看重叠残差和实际图案，不能只用一个算法分数验收。
3. 如果匹配点显示稳定水平位移，可按全圈位移总量转换为环绕坐标；如果不是，改用相机投影/非线性校准，不把一次项目的坐标常量直接移植。
4. 在同一个连续标签表面设置各来源UV和窄范围混合。拼接边界应选在两张图都有足够清晰信息的位置，不在文字错位时靠扩大模糊区域掩盖问题。
5. 原图明暗已经烘焙进颜色，新场景又会重新照明。可在材质中有限补偿亮度，但不能声称恢复了原始印刷色。用蓝底等均匀色块估算时排除文字、插画和高光，并核对是否误伤图案。
6. 检查正/侧/背/接缝区域，再把每处真正的贴图拼接边界转到镜头中央检查。旋转整只产品，不能只切换标签假装验证三维结构。

## 验收与常见误判

- 标题和图案数量正确，无镜像、重复或缺段；金边和横线连续。
- 普通展示距离下衔接自然；重要文字的局部特写也需检查。
- 用户提供的新图可能是不同SKU、不同组分或标签版本，先核对品名和图案。不要因文件名前缀相同就混用。
- 提手在真实侧视时变窄是正常现象；若参考效果图所有方向提手均同样宽，应说明参考图的展示方式，不修改实际三维几何去追随该假象。
- 模糊小字、认证标识与二维码不能靠AI猜测补齐。必要时向用户索取原内容，或限定展示距离。
- 只有部分视角成立时明确标注，不生成或宣称已验证完整360度展示。
