# 动画、旁白与交付

## 镜头与计算量

- 先根据用途定画幅，电商并非一律方形。用户未指定平台时可提出合理默认，注明当前选择。
- 简单10秒示例：0—3秒整体亮相，3—6秒小幅环绕，6—8.5秒品牌推进，8.5—10秒正面定格。这是示例，不能覆盖用户已经给定的镜头。
- 24fps、10秒对应240帧；Blender帧1—240。镜头硬切要落在相邻帧，避免插值穿过不希望显示的位置；运动缓动检查是否过冲。
- 先渲染全景、环绕端点、最大近景和片尾关键帧，确保画幅变化后裁切仍合理。
- 同一产品在所有镜头共用资产。以父级控制旋转，保留对象局部结构。光照、材质、几何和动作问题分别定位。
- 优先复用相同场景、硬件与目标规格的有效测量；缺少数据时测试目标规格帧。用实测单帧时间×动态帧数估算，另留编码余量。CPU性能、采样、分辨率和场景会改变耗时；不要承诺固定分钟数。
- 真正不变的定格可以复制已完成帧；相机、物体、灯光、模拟或随机种子仍变化时不能这样做。不用重复低帧率画面冒充真实更高帧率渲染。

## 修改后只重渲染受影响部分

- 先判断变化影响哪些镜头与帧段。只改某台相机可重渲染对应镜头；共享模型、灯光、环境或模拟变化可能影响全片，不能仅凭文件名认定其他帧可复用。
- 已证明不受影响的帧可复制到新输出目录，保留原版本，记录源工程、帧范围、规格与文件哈希。续跑脚本的工程哈希保护不允许关闭；跨版本复用应另做来源记录。
- 全局色彩管理、渲染引擎、分辨率或采样变化时重新判断一致性。局部替换后检查切镜、光照和运动衔接，再按下面的清单检查新成片。

## 旁白

- 从已确认品名、用途描述和品牌文案起草简短文案，先合成再测时长；字数不能精确决定时长。
- 只有实际生成或修改语音时，读取已选服务所需指导；复用现有音轨不加载配音技能。检查凭据是否存在只输出布尔值，不显示密钥。缺少某服务不等于所有配音均被阻断；采用可用替代工具时告诉用户实际来源，不冒充原服务。
- 具体声线是选择，不固定绑定本案例男声。不使用未经请求的声音克隆。
- 技术可调用不证明任意服务的商用授权。用户涉及发布授权或特定服务许可时核对实际条款，不宣称所有生成音频都免费商用。
- 用ffprobe测量旁白。过长时先精简文案、适度调速或与用户协商延长镜头，不能直接截掉末尾词句。
- 调整音量后重置时间戳，再添加开场留白和片尾静音；导出后检查音轨时长。一次案例里不重置时间戳导致目标10秒音轨只有9.716秒，不能只相信命令参数。
- 若改视频旁白，已通过画面可流复制；新画幅或新镜头需要三维重渲染。是否加音乐、字幕由任务决定。

## 合成与检查

需要FFmpeg时优先使用可用的 ffmpeg-video-editor 技能；否则使用本机工具并验证输入参数。以下命令仅示范240张24fps帧和已处理10秒音轨：

```powershell
ffmpeg -framerate 24 -start_number 1 -i '<frames>/frame_%04d.png' -i '<narration.wav>' -map 0:v:0 -map 1:a:0 -frames:v 240 -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p -c:a aac -b:a 192k -t 10 -movflags +faststart '<output.mp4>'
ffprobe -v error -count_frames -show_streams -show_format -of json '<output.mp4>'
ffmpeg -v error -i '<output.mp4>' -f null -
```

旁白时长须提前检查，上例的 `-t 10` 不能代替这一检查。无旁白时去掉音频输入及映射。

完成标准（仅适用于本次交付范围）：

同一文件版本的有效检查结果直接复用。新导出视频执行规格、完整解码与相关视听检查；仅修改音轨时复查音频和同步，不重复渲染已通过的画面。工程发生改动或重新打包时检查可重开与依赖；只改剪辑或文档不重查未变工程。检查失败或存在未解决疑点时复查相关项。
- 规格与确认一致；音视频时长和帧数正确；全片解码成功。
- 检查编码文件抽帧、切镜前后帧和近景；有条件时实际播放听看。没有听过音频不声称完成听感验收。
- 工程可重开，图像和音频打包或随工程明确提供。几何缓存和外部模拟文件另外核对。
- 若音轨在Blender序列器，而帧序列需要直接渲染三维场景，核实 `render.use_sequencer`；说明工程里的声音与最终FFmpeg合成方式。
- 提供MP4、用户要求的静态图、工程和简短重现说明。保留已通过版本与原素材，不自动上传店铺或替换线上文件。
