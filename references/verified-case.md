# 项目经验与可复现示例

这个技能整理自一次桶装产品展示制作：从四张效果图重建外观和环绕标签，完成10秒运镜、普通话旁白及1080×1080成片。公开仓库不包含该品牌的标签、照片、音轨或工程。

## 实际遇到的问题

- 四张图片共用同一桶体和提手视角，标签内容近似水平平移。直接按四个90度圆柱相机拼接会错位，需通过重叠图案判断投影方式。
- 正面投影可以很快验证外观，但不能证明背面已完成。需要把实际贴图拼接边界转到镜头中央检查。
- 原图含光影，贴到三维模型后又经历一次照明，容易产生明暗断层。有限补偿能改善展示，但不能还原未知的印刷原色。
- 低清运镜、声音和画幅先通过后才渲染高清。同样10秒，CPU高清渲染可能需要约一小时；先测单帧再估算，不能按低清速度承诺。
- 最终工程打包图像与音频，重新打开检查；FFmpeg核对帧数、音轨时长并完整解码。

这些是一个项目中的观察，不是所有产品的几何、成本或质量保证。

## 仓库里的示例

`examples/create_demo.py` 使用几何体和程序化材质生成无品牌包装场景，输出可编辑工程及一张图片。它演示脚本执行、场景保存和真实渲染，不演示缺少展开图时的多图重建。

```sh
blender --background --python examples/create_demo.py -- --output output/demo
```

随后可使用 `scripts/render_frames.py` 对工程渲染。示例仅设有轻微转台动画，完整宣传片仍需要按产品需求编排镜头。
